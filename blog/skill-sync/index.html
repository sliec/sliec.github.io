用 Agent Skill 实现跨平台能力同步

2026-07-28 · 工程化 · Skills

换一台电脑，或者换一个 AI Agent 平台工作，最烦的事情不是装环境，而是重新配置那些已经调教好的「能力」——Prompt 模板、工作流定义、输出规范。每次都要从零开始，费时且容易遗漏。

这篇文章分享一个解决方案：用 GitHub 仓库集中管理 Agent Skills，一行命令全平台同步。

什么是 Agent Skill？

在 QoderWork / QoderCLI 这类 Agent 平台中，Skill 是一份结构化的指令文档（SKILL.md），告诉 Agent「什么时候该做什么、怎么做」。比如一个统计分析 Skill，会定义数据诊断流程、方法选择逻辑、输出格式规范。

有了 Skill，Agent 不再是一张白纸，而是一个有专业知识的工作伙伴。

痛点：Skills 散落各处

用了一段时间后，你会积累十几个甚至几十个 Skills。但它们通常散落在本地目录里：

  • 换电脑？手动复制，经常遗漏
  • 换平台？重新写一遍
  • 团队协作？无法共享
  • 版本管理？不存在的

方案：一个仓库，全平台同步

思路很简单：把所有 Skills 放到一个 GitHub 仓库里，需要时克隆到本地。

# macOS / Linux
git clone https://github.com/sliec/shared-files.git
cp -r shared-files/skills/* ~/.qoderwork/skills/

# Windows PowerShell
git clone https://github.com/sliec/shared-files.git
Copy-Item -Recurse -Force shared-files\skills\* "$env:USERPROFILE\.qoderwork\skills\"

一行命令，20 个 Skills 全部就位。仓库里目前包含 6 大类技能：

类别代表技能能力
金融分析equity-fund-attribution权益基金业绩归因全流程
数据分析statistical-analysis问卷/实验数据的统计分析
产品管理prd-doc-writerPRD 文档撰写
思维学习problem-goal-defined问题定义与目标拆解
系统设计fireworks-tech-graph12 种风格画技术架构图
存储管理storage-analyzer磁盘空间分析与清理

按需安装单个 Skill

如果不想全量同步，也可以只安装需要的 Skill：

SKILL=statistical-analysis
mkdir -p ~/.qoderwork/skills/$SKILL
curl -o ~/.qoderwork/skills/$SKILL/SKILL.md \
  https://raw.githubusercontent.com/sliec/shared-files/main/skills/$SKILL/SKILL.md

替换 SKILL 变量名即可安装任意技能。

Skills 的三类来源

仓库里的 Skills 来自三个渠道：

个人原创：工作中沉淀下来的专业技能，比如基金归因系列（权益/固收/FOF 三个技能）、问题拆解工具、C 盘清理工具。

社区精选：来自优秀开源作者的作品，比如 TerryFYL 的统计分析顾问、yizhiyanhua-ai 的技术架构图绘制、云舒的 PRD 系列工具、卡兹克的深度研究工具。已标注来源和 License。

持续迭代：使用过程中发现的问题和改进点，直接在仓库里更新，下次同步时自动获取最新版本。

一个好的 Skill 长什么样？

从实践中总结的标准：

  • 清晰的触发条件：Agent 知道什么时候该调用这个技能
  • 完整的工作流程：从输入到输出，每一步都有定义
  • 标准化的输出：比如统计分析的 APA 三件套（表格 + 图表 + 结果段落）
  • 不含个人信息：API Key、本地路径等不能写死在 Skill 里

小结

Skills 是 Agent 能力的载体，值得像代码一样管理。一个 GitHub 仓库 + 一行同步命令，就能实现跨电脑、跨平台的能力复用。
