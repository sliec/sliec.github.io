📅 推荐 4 周学习路径

从零开始，系统化学习 AI Agent 搭建

1

第一周：基础入门

读完 hello-agents 前 5 章 + ai-agent-book 第 1-2 章。建立 Agent = LLM + 上下文 + 工具的核心认知

2

第二周：深入核心

hello-agents 第 6-10 章 + ai-agent-book 第 3-5 章。重点理解上下文工程、记忆系统、工具调用（MCP）

3

第三周：动手实验

ai-agent-book 第 6-8 章的实验项目 + 用 fireworks-tech-graph 画自己的 Agent 架构图

4

第四周：进阶实战

ai-agent-book 第 9-10 章（多模态 + 多 Agent）+ 用 AutoAgent 或自选框架搭建一个完整 Agent 项目
