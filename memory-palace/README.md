## 这本书在讲什么

市面上的记忆书大多在教你一个个孤立的"技巧"——联想法、宫殿法、数字编码——读完之后你会很多方法，但不知道什么时候用哪个、怎么组合起来应对真实的学习场景。

这本书的目标不是给你一把锤子，而是给你一套**记忆操作系统**：

```
原理层 → 为什么能记住（大脑机制）
方法层 → 怎么让信息变得好记（编码 + 空间 + 理解）
系统层 → 怎么把方法组合成一个可长期运转的系统
实战层 → 面对具体考试/场景该怎么用
```

## 每章统一结构

每章都遵循相同的写作格式，方便你按需查找：

1. **原理一句话** — 这个方法为什么有效
2. **操作步骤** — 具体怎么做
3. **案例** — 真实场景演示
4. **常见误区** — 容易踩的坑
5. **适用边界** — 什么情况该用、什么不该用

## 这本书适合谁

- 正在备考法考、CPA、考研等大量知识点考试的人
- 觉得"背了就忘"、想要系统性提升记忆效率的人
- 对记忆方法感兴趣、想要一套完整框架而非零散技巧的人

## 怎么读这本书

- **从头到尾读**：按章节顺序，建立完整知识体系
- **按需查找**：直接跳到你想学的具体方法（如第 14 章记忆宫殿）
- **先读原理再读实战**：第 1-4 章 → 第 26-30 章，中间方法章按需补充
